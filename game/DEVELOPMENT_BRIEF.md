# 开发要求：阿萨拉小兵的炒股梦

请继续修改本包代码，不从空白重做。先读取页面、测试和用户截图。

## 1. 定位和范围
玩家是驻守零号大坝的阿萨拉卫队小兵，用积蓄偷偷炒股，想赚够钱离开哨所。
中文浏览器小游戏，手机电脑直接玩，面向普通人和学生。只有看行情、买卖股票、打工。
本次重点：界面可用 -> 真实地图与哈夫币 -> 阵营事件联动 -> 游戏氛围。
不添加小鸭、阿萨拉小兵立绘、具体物资图鉴、背包、装备交易、射击、搜打撤、经营、借贷、做空、抽卡、技能树或复杂任务。

## 2. 阵营关系（必须纠正）
阿萨拉国家、旧王室政府、阿萨拉卫队不是同一个概念。
- 阿萨拉卫队与哈夫克敌对。早期与哈夫克合作的是旧王室政府，不能写成卫队与哈夫克合作。
- GTI与哈夫克对抗，调查、搜集证据并展开行动。
- GTI不是阿萨拉卫队盟友，双方不会因为都对抗哈夫克就自动合作。
- 所采用背景中零号大坝由阿萨拉卫队控制，赛伊德负责驻守。
- 新事件考虑地点控制权与行动动机。不能随便写“哈夫克替卫队维修电站”“GTI帮卫队恢复工程”。
- 帮助可以体现为帮助平民、维护自身设施、或行动间接缓解另一方压力。

官方参考：https://www.playdeltaforce.com/act/wikimap/
此前已读取的官方页面摘要：旧政府与哈夫克合作应对能源问题，控制加深后与卫队冲突升级；大坝由哈夫克和王室合作建设，内战后卫队控制；赛伊德隶属卫队、驻守大坝；GTI进入阿萨拉调查哈夫克，卫队控制主要道路并拒绝外交接触。这个摘要让断网环境也能理解关系，不是完整官方文档。
股票上市、证券市场、具体新闻、事件链和行情影响均为小游戏二次创作，不是官方剧情；贴吧推测不能写成官方事实。

## 3. 用户素材
使用 reference/assets 下的两张PNG。
- 地图替换当前原创示意图，保留真实地点关系，可裁去无关外围UI，但不能错位或随意重排建筑。原图并非完整地图，优先使用能准确定位的地点。响应式缩放后高亮仍要对齐，使用归一化坐标或等效方案。
- 哈夫币图标用于资产、现金、收入等位置，去掉人民币 ¥，必要时标注“哈夫币”。检查棋盘格是否烘焙进图片，处理干净后接入，保留原图。
- 成品素材随 dist 打包，避免依赖外链。无法读取素材时报告具体缺少哪个文件，不以自画替代图冒充。

## 4. 界面
黑灰底、冷白文字、亮绿强调，主绿 #0FF796 或 #11F89E；不用橙色主按钮。
避免大量装饰框、无用英文编号和专业证券指标。
顶部：名称、天数、总资产、现金、暂停。
电脑：K线占主要空间，地图与当前事件在旁边。
手机：优先K线与交易，地图可收起展开，当前消息始终可读。
图表附近：三只股票、日期、缩放、回看。
底部：持仓、平均成本、盈亏、半仓/全部、买入、卖出、打工。
知识提示独立一行，不能遮挡图表。
正常尺寸尽量单屏；小屏和浏览器缩放时允许自然滚动，不强行压扁图表，不用悬浮底栏遮住数据。现有CSS有多次叠加，必要时整理。

## 5. 地图事件
广播出现 -> 地点亮起 -> 影响相关股票走势倾向 -> K线留下标记 -> 后续消息更新状态。
地点可用水泥厂、主变电站、军营、行政辖区等，必须在原图准确定位。未显示的游客中心等地点不得猜坐标。
以下均为原创事件方向，不是官方剧情：
- 哈夫克封锁大坝外围运输路线，对卫队施压，运输、交付与成本预期变化。
- GTI袭击哈夫克封锁设施，间接减轻卫队压力，但没有成为友军。
- GTI潜入行政辖区调查，卫队提高警戒，小兵又要加班。
- 卫队组织抢修道路，恢复自身控制区通行，基建订单可能增加。
- 哈夫克维修自己的设施，为自身项目服务。
部分事件有两三步后续，例如封锁 -> 行动 -> 解除或持续。一次突出一件主要事件，不增加额外确认或任务系统。
消息写清楚谁、在哪里、做了什么、业务如何受影响。区分卫队广播、哈夫克公告、截获通讯、同伴传闻；传闻不能当确定事实。
同一事件可影响多只股票，方向强度不同。只改变概率和短期趋势，不保证利好上涨。三股独立波动。
少量小兵式幽默，例如广播骂哈夫克，玩家却持有哈夫克股份。避免大量梗、口号与长设定。

## 6. 股票与规则
哈夫克股份：科技、大型项目。哈德逊工业：工业、装备订单。阿萨拉基建：当地工程、道路修复（原创企业）。所有上市安排是二创，不新增GTI股票。
开局10000哈夫币，无持仓；30天，每20秒一天，每秒更新行情，约10分钟。
总资产=现金+所有持仓市值；达到1000万立即获胜，否则30天结束。极难挑战，不让股票必涨。
半仓/全部选择，加买入/卖出两个按钮。半仓买入用一半现金且含手续费；半仓卖出一半股数向下取整。
买卖各收0.1%手续费，明确显示成交费用。整数股，不出现负现金或持仓。平均成本含买入手续费，浮盈亏注明未扣卖出费。
打工一个按钮，赚500哈夫币、推进20个行情tick；不足一天禁用，推进中达到目标立即结束。处理连点。
暂停冻结行情和交易打工，仍可回看；后台自动暂停，回来手动继续。

## 7. K线
每5秒一根真实OHLC，当前蜡烛随每秒行情变化，价格为正，短期趋势结合随机波动。
显示游戏日日期、价格轴、现价、涨跌幅；涨跌除颜色外有正负号或箭头。
默认近期行情，支持缩放回看，避免早期极端价格把后期压成直线。历史视图不要被当前价拉大量程。
标记买卖与新闻，点击查看。成本线在图外就注明，不为显示成本强行扩大价格轴。
回看不暂停时间，明确实时/历史状态。不加入MACD等专业指标。

## 8. 知识与结算
每局每个知识点一句话提示一次，不弹窗、不遮挡。内容包括所有权、不保本、集中持仓风险、手续费、利好未必上涨，不能暗示频繁交易稳赚。
保留：“行情为虚构且波动夸张，1000 万是游戏挑战，不代表现实投资回报。”
结束显示资产、收益率（含打工）、称号、再玩一次。仅本地最高分，存储不可用也能玩。
重开清空行情、持仓、事件链、地图状态、提示、时间、回看选择与缩放。页面始终只保留一个计时器。

## 10. 验证交付
本包文件即可离线开发，不因原网址403而停止。保持HTML/CSS/JS、纯前端、无账号、无后端API。
检查开始、交易与费用、资金不足、1股半卖、重复点击、打工、事件阶段与阵营逻辑、地图缩放定位、K线聚合标记、暂停后台、立即获胜、30天结算、重开、存储失败。
真实浏览器检查电脑、手机、小窗口、浏览器放大。没有浏览器能力必须如实说明，不把DOM模拟叫实机测试。
完成后交付完整可运行文件；有已授权可用的部署渠道再给实际链接。原站权限不随本包转移，不声称更新未实际发布的网址。不要扩大玩法。
