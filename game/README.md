# 阿萨拉小兵的炒股梦 · 阿萨拉值守版

驻守零号大坝的卫队小兵，用 10,000 哈夫币开始 30 天的炒股生活。看行情和广播、半仓/全部买卖、打工。红黑界面，无登录、后端、付费服务或 API Key。

试玩地址：https://mingwoke.github.io/8855441631df/

本轮整理和实现依据：[开发方案](docs/REVISION_PLAN.md)。`DEVELOPMENT_BRIEF.md` 保留原始交接要求；其中的绿色主题、1,000 万目标、500/一天打工已由本轮用户要求替代。

## 本轮内容

- **100 万**终极目标；3 万、10 万、30 万积蓄节点与不同结算反馈。
- 降低随机波动，去除工业股随机大跳价。普通日与事件日设置波动边界，新闻仍不保证涨跌。
- 打工赚 **1,000**、演算 **10 秒（半天）**；工资、期间持仓变化和新广播分开显示。
- 三种开局，12 组、31 个原创事件分支；道路和供电持续影响行情及后续交付概率。最近三条广播可展开补看。
- 三股业务说明、成交金额和手续费预览、各股持仓提示、分股收益结算。
- 原始地图和哈夫币随网页打包。取消地图放大弹窗，手机保留地图折叠。地图每次只突出一处事件。

100 万仍然极难。固定种子样本中，示例策略未达成终极目标，不能把规则可运行说成一般玩家能够通关。详见数值报告。

## 本地运行

在本目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

用浏览器打开本机的 4173 端口即可。也可尝试直接打开 `dist/index.html`；本次受管理的 Chromium 禁止 `file://`，因此直接文件方式未验证。通过本地 HTTP 加载后，断网仍可继续游戏。

部署时完整上传 `dist`，保留 `styles.css` 和 `assets` 的相对路径。GitHub Pages 使用专门的 `gh-pages` 分支，见仓库根目录 `DEPLOYMENT.md`。此前的 chatgpt.site 地址未更新。

## 验证

```sh
node tests/game.cjs
node tests/balance.cjs
node tests/browser.cjs
```

前两项只需 Node.js。本次使用 Node 24.19.0；浏览器测试使用 Playwright 1.62.1 与 `/usr/bin/chromium`。可通过 `CHROMIUM_PATH` 指定 Chromium。需要安装 Playwright 时：

```sh
npm install --no-save --package-lock=false playwright@1.62.1
```

浏览器测试自行启动临时 HTTP 服务并关闭，使用独立浏览器环境，不读取个人浏览器资料。

本轮 **52 项逻辑/DOM 检查、27 项真实 Chromium 检查通过**。另有 1,000 局市场路径与 1,501 局策略样本；结果及截图在 `verification/`，说明见 `TEST_RESULTS.txt`。覆盖桌面、手机触屏模拟、小窗口及原生浏览器 200% 缩放；不是实体手机或 Safari 测试。

## 保留规则

每秒更新行情，每五秒一根 OHLC 蜡烛；每 20 秒一天，30 天共 600 ticks。整数股，买卖各收 0.1%，买入费计入成本。结算净收益已包含已付手续费，持仓按市价计，未扣尚未发生的卖出费用。达到目标立即结束。暂停冻结行情和操作但可看图；切到后台自动暂停，回来手动继续。重开重置全部本局状态，页面只使用一个计时器。本地只保存最高资产，存储不可用仍可玩。

采用交接包的背景：卫队与哈夫克敌对；GTI 对抗哈夫克但不是卫队盟友；卫队控制大坝，赛伊德驻守。股票、企业「阿萨拉基建」与具体新闻都是二次创作。

**行情为虚构且波动夸张，100 万是游戏挑战，不代表现实投资回报。**
