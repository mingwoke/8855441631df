# 阿萨拉小兵的炒股梦 · 阿萨拉值守版

驻守零号大坝的卫队小兵，用 10,000 哈夫币开始 30 天的炒股生活。看行情和广播、按比例或指定股数买卖、打工。红黑界面，无登录、后端、付费服务或 API Key。

试玩地址：https://mingwoke.github.io/8855441631df/

本轮整理和实现依据：[开发方案](docs/REVISION_PLAN.md)。`DEVELOPMENT_BRIEF.md` 保留原始交接要求；其中的绿色主题、1,000 万目标、500/一天打工已由本轮用户要求替代。

## 界面与操作（2026-10-18 最新）

- 删除「卫队档案」。开始页只保留身份、目标、主要规则和进入按钮。
- 主界面按窗口高度分配空间。资产、天数、行情、当前消息入口、持仓和买入/卖出/打工在同一屏；手机使用股票选择器，电脑并排显示六股报价，较矮横屏把交易放在图表右边。
- ¼仓、半仓、¾仓、全部：买入用相应比例现金，卖出用相应比例持股，向下取整。「股数…」输入正整数，只设置数量，再点买卖成交。超出现金或持股直接禁用，不悄悄改变订单数量。
- 主按钮显示预计股数，打工显示确切工钱；点「费用 / 工种」查看含手续费的金额预览和工作内容，底部回执保留本次费用，可点开完整报告。
- 点「持仓」查看六股持仓、成本与浮盈亏；手机点广播读正文/切换历史，点「局势」看原图与地点状态。完整记录的阅读面板可滚动，主操作区不被长内容撑开；阅读不暂停行情，内容为打开时的快照。
- K线采用3天/7天/全局、横向拖动、左右翻页、回到最新。左右按钮在回看时保持可用；点标记直接阅读消息/成交，点蜡烛后可打开日期与OHLC详情。键盘左右选择、Home最早、End最新。
- 主要标签至少14px、主按钮18px；窄屏的次要图注/状态采用13px，极窄或横屏少量辅助项12px。深绯红与冷黑、涨绿跌红保持。

## 六只股票与局势

| 股票 | 业务与主要影响 |
| --- | --- |
| 哈夫克股份 | 大型项目、调查和回款风险 |
| 哈德逊工业 | 工业订单、生产与交付 |

三种开局，13组、34个原创事件分支。既有31个分支补齐新增业务的不同方向/强度影响，另增通信中断→修复或延期。所有六股均参与行情、新闻标记、交易、持仓、总资产与分股结算。没有GTI股票；卫队与哈夫克敌对，GTI不是卫队盟友。

100万终极目标、3万/10万/30万积蓄节点，12种工作500～2,000哈夫币/半天，接活前报价、最近两项避重复、局势限定工作与独立工资随机序列均保留。地图和币面使用用户原图，徽记为用户截图清理版。本版不增加地图缩放。

100万仍极难：最新固定种子样本中，九种示例策略各300局均未达标；样本不等于真实玩家胜率，也不证明数学上不可达。

## 本地运行

在本目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

用浏览器打开本机的 4173 端口即可。也可尝试直接打开 `dist/index.html`；本次受管理的 Chromium 禁止 `file://`，因此直接文件方式未验证。通过本地 HTTP 加载后，断网仍可继续游戏。

部署时完整上传 `dist`，保留 `styles.css` 和 `assets` 的相对路径。GitHub Pages 使用专门的 `gh-pages` 分支，见仓库根目录 `DEPLOYMENT.md`。此前的 chatgpt.site 地址未更新。

## 保留规则

每秒更新行情，每五秒一根 OHLC 蜡烛；每 20 秒一天，30 天共 600 ticks。整数股，买卖各收 0.1%，买入费计入成本。结算净收益已包含已付手续费，持仓按市价计，未扣尚未发生的卖出费用。达到目标立即结束。暂停冻结行情和操作但可看图；切到后台自动暂停，回来手动继续。重开重置全部本局状态，页面只使用一个计时器。本地只保存最高资产，存储不可用仍可玩。

采用交接包与用户第一张卫队档案截图的背景：卫队与哈夫克敌对；GTI 对抗哈夫克但不是卫队盟友；卫队控制大坝，赛伊德驻守。用户已取消第二张背景图，仅使用第一张。股票上市、企业「阿萨拉基建」「大坝运输」「阿萨拉能源」「绿洲通信」、打工安排与具体新闻都是二次创作。徽记处理来源见 [素材说明](docs/EVENTS_AND_ASSETS.md)。

**行情为虚构且波动夸张，100 万是游戏挑战，不代表现实投资回报。**
