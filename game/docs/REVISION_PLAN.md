# 本轮开发方案：一屏操作与六股交易

2026-10-18，依据用户最新反馈。此方案优先于交接文档中三只股票、半仓/全部、绿色主题、1,000万目标以及旧版允许主页面纵向滚动的要求。

## 用户问题与实施范围

1. 删除「卫队档案」，收紧开始页的标题、徽记、说明和地图占用。
2. 主要操作适应一屏：顶部资产/现金/天数/暂停，中间K线，底部持股/成本/浮盈亏、仓位和买卖/打工。手机用原生选择器切股、短广播入口；低横屏将图表和交易并列。长记录、持仓总览和局势按需打开，不参与主布局高度。
3. 订单支持¼、½、¾、全部，加自定义正整数股数。比例买入按可用现金预算且包含手续费，卖出按持股比例取整。自定义数量不足以成交时拒绝，保留原输入。
4. 股票从三只扩至六只。保留原三股，新增原创的大坝运输、阿萨拉能源、绿洲通信。分别补齐行情参数、事件暴露、真实买卖、持仓汇总、新闻标记和收益结算。
5. 新增通信检修事件链；原31分支明确增加三项业务影响，合计13组34分支。一次仍只突出一个地点、一条主要事件链，不新增任务确认或其他玩法系统。
6. 回看保持左右翻页按钮；当前价和历史OHLC分开，长消息和打工复盘进阅读面板，成交费用仍明确可见。

## 保留规则与氛围

- 10,000哈夫币开局、100万挑战、30天/每天20秒、每秒行情、5秒OHLC。达到目标立即结算。
- 行情采用既有缓慢趋势和普通/事件日边界，无保证上涨。新增股票独立噪声、业务事件和地区状态影响；扩股会改变同种子的随机抽样路径，必须重新跑数值报告。
- 买卖各0.1%手续费，买入费计入平均成本；浮盈亏未扣未来卖出费。工资500～2,000/半天，12种，报价先显示，行情同步演算。
- 冷黑与深绯红阿萨拉界面、卫队徽记、涨绿跌红。主按钮18px、主要标签14px，不用全页缩放硬塞内容。
- 卫队与哈夫克敌对；GTI调查哈夫克但不是卫队盟友。零号大坝由卫队控制、赛伊德驻守。股票上市、原创公司和具体金融消息为二创。
- 不增加借贷、做空、装备、背包、技能树、任务树或GTI股票；不增加地图缩放。

## 验证与交付

- 逻辑测试覆盖全部六股、34分支、比例/自定义数量、费用、成本、资金守恒、后台暂停、结算和单计时器重开。
- 浏览器检查开始页和主屏文档无横/竖滚动、图表/数字/按钮无交叠，覆盖320×568手机、横屏、小窗口和原生200%缩放。完整阅读面板/六股明细/结算长内容允许内部滚动，不能声称无限小窗口或任意系统字号仍能完全一屏。
- 实际操作四种比例、自定义输入与错误、六股交易、事件轮换、打工、历史、暂停、结算和重开；使用不同种子的完整30天流程对账。
- 重跑1,000局市场路径与六股各300局持有等2,700局策略，记录波动与挑战难度，不把样本当真实胜率。
