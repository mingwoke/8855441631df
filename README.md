# 阿萨拉小兵的炒股梦

中文纯前端浏览器小游戏。开局 10,000 哈夫币，驻守零号大坝 30 天，看消息、买卖股票、打工，挑战攒到 100 万。

本版采用红黑阿萨拉界面，降低随机波动，打工改为 1,000/半天，加入持续地图状态、12 组原创事件和收支复盘。代码在 `game/`，网站发布文件在 `gh-pages` 分支。
