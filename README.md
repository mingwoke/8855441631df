# 阿萨拉小兵的炒股梦

中文纯前端浏览器小游戏。开局 10,000 哈夫币，驻守零号大坝 30 天，看消息、买卖股票、打工，挑战攒到 100 万。

本版采用深红黑阿萨拉界面与卫队徽记，行情涨绿跌红。打工有 12 种，每半天报酬 500～2,000，接活前明示；地图局势影响可接工作。保留较平缓行情、持续地图状态、12 组原创事件和收支复盘。代码在 `game/`，网站发布文件在 `gh-pages` 分支。
