# 阿萨拉小兵的炒股梦

中文纯前端浏览器小游戏。开局 10,000 哈夫币，驻守零号大坝 30 天，看消息、买卖股票、打工，挑战攒到 100 万。

- [在线试玩](https://mingwoke.github.io/8855441631df/)
- [游戏说明与本地运行](game/README.md)
- [本轮开发方案](game/docs/REVISION_PLAN.md)
- [验证结果](game/TEST_RESULTS.txt)
- [发布说明](DEPLOYMENT.md)

本版采用冷黑背景、深绯红按钮与局部红色边线，保留卫队徽记，行情涨绿跌红。打工有 12 种，每半天报酬 500～2,000，接活前明示；地图局势影响可接工作。保留较平缓行情、持续地图状态、13 组原创事件和收支复盘。代码在 `game/`，网站发布文件在 `gh-pages` 分支。

最近更新：移除卫队档案，开始页和主操作界面按窗口高度排布；股票扩展为六只，增加四档比例与自定义股数。主屏显示资产、行情、当前广播、持仓与买卖/打工，完整记录和局势按需打开。详见 [界面调整与验证](game/docs/QUALITY_REVIEW.md)。
